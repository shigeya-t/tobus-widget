# 都バス接近情報 1.0.0

都営バスのバス停への車両接近情報と、本日の残りの定刻を、メニューバーとデスクトップのウィジェットに出しておく macOS アプリです。
自分でビルドしなくても、DMG から入れられる最初のリリースです。

## インストール

1. DMG を開き、**TobusWidget** を **Applications** フォルダへドラッグします。
2. アプリケーションフォルダから **TobusWidget** を起動します。Dock には出ず、メニューバーにバスのアイコンが出ます。
3. メニューバーのアイコンをクリックし、バス停名で検索して選び、系統（のりば×行き先）を選びます。
4. デスクトップを右クリック →「ウィジェットを編集」→ 左の一覧から **TobusWidget** を選び、ウィジェット「都バス接近情報」を配置します。
5. 置いたウィジェットを右クリック →「ウィジェットを編集」で、ウィジェットごとにバス停・系統を選べます。
6. 常用するなら、システム設定 →「一般」→「ログイン項目」に登録してください。**ウィジェットが更新されるのはアプリが起動しているあいだだけです。**

ウィジェットギャラリーの一覧の名前が「TobusWidget」なのは仕様です（`.app` のファイル名を日本語にするとウィジェット拡張が起動できなくなるため。メニューバー等の表示名は「都バス接近情報」です）。

**動作条件:** macOS 14 以降。API キーや登録は不要です。

## できること

- **接近情報** — 実車が接近中なら「約N分後」、実車情報が無い時間帯は tobus.jp の定型文をそのまま表示
- **本日の残りの定刻** — 平日 / 土曜 / 休日のどのダイヤかを見出しに明記。本日分が終わったら翌日の始発に切り替え（翌日の区分は曜日からの推定なので「翌 平日ダイヤ」のように表記）
- **行き先記号つきの便と凡例** — 「ｱ」「ﾛ」など途中止まりの便も落とさず、記号説明を凡例として表示
- **ウィジェット（小・中）** — 複数置いて、それぞれ別のバス停・系統を表示できます。右上のボタンで更新できます
- **古いデータの警告** — 10 分以上更新できていなければ ⚠️ を表示
- **一時停止** — 使わない時間帯は通信を完全に止められます

## 最近の主な変更

- macOS 27.2.1 で、ウィジェットの編集画面で系統を選んでも表示が変わらない問題を避けるため、系統の選択肢を検索つきリストにしました（#14）
- 長い行き先がウィジェットのヘッダーで切れないようにしました（#13）
- 通信タイムアウトの設定、検索語のログ秘匿、手動更新の間引き、日付またぎの取得時刻の修正（#12）
- 小ウィジェットでも次の定刻を 3 件出すようにしました（#11）
- 日曜・祝日まわりで本日のダイヤ区分を取り違える問題を直しました（#5, #8, #9, #10）
- 定刻を毎分載せ直し、時間が過ぎた便が残らないようにしました（#6, #7）
- 配布に向けて hardened runtime を有効にしました

## ご注意

- **以前に自分でビルドして入れていた場合は、先にそちらを削除してください**（`~/Applications/TobusWidget.app` など）。同じアプリが 2 か所にあると、ウィジェットが空やプレースホルダのままになることがあります。配布版は自前ビルドと App Group が異なるため、選択中のバス停・系統や一時停止の状態は引き継がれません。配置済みのウィジェットも、置き直して選び直してください。
- **非公式な利用です。** 都バス運行情報サービス（[tobus.jp](https://tobus.jp/blsys/navi)）の公開画面を取得して解析しています。公式 API ではないため、先方のページ構成が変わると突然表示できなくなることがあります。本アプリは東京都交通局とは関係ありません。
- 詳しい使い方とトラブルシューティングは [README](https://github.com/shigeya-t/tobus-widget#readme) を参照してください。
